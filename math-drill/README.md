# 中学数学 図解ドリル

中学校数学の演習問題を、図（座標平面のグラフ・図形・立体の見取図・ヒストグラムなど）つきで自動生成する1ファイルのWebアプリです。
`index.html` をブラウザで開くだけで動きます（ビルド不要）。理科版（`../science-drill/`）と同じ画面構成です。

## 収録単元（20）

| 分野 | 中1 | 中2 | 中3 |
| --- | --- | --- | --- |
| 数と式 | 正負の数、一次方程式の文章題 | 連立方程式の文章題 | 平方根と展開・因数分解、二次方程式の文章題 |
| 関数 | 比例・反比例 | 一次関数のグラフ、一次関数の利用（動点） | 関数 y＝ax² |
| 図形 | おうぎ形、空間図形 | 平行線と角・多角形、三角形・平行四辺形 | 相似、円周角の定理、三平方の定理 |
| データの活用 | 度数分布とヒストグラム | 確率、箱ひげ図 | 標本調査 |

## 使い方

- 単元を選び（学年ボタンで一括選択可）、問題数（2〜20問）を決めて「新しいプリントを作る」。
- 各問題の「数値を変える」で、その問題だけ別の数値に作り直せます。
- 「解答・解説」を開くと答えと解き方が出ます。補助線や作図が要る問題（平行線と角、一次関数、y＝ax²、円錐の展開図、確率の表・樹形図、箱ひげ図など）は解答側に図がつきます。
- シード番号を入れて「再現」すると、同じプリントをもう一度作れます。
- 「印刷する」で名前欄つきのプリントとして印刷できます。解答をすべて開いた状態で印刷すると解答つきになります。

## 数値の作り方

- 答えを先に決めてから、問題の数値を逆算しています（例：一次関数は交点を格子点に置いてから直線を決める）。
- 分数は既約分数、平方根は a√b の形で表示します（`fr` / `rt` / `frRt` / `piS` 関数）。
- 三平方の定理はピタゴラス数と 1:1:√2、1:2:√3 の三角形を使います。

## 単元を追加するには

`genXxx()` 関数を書いて `UNITS` 配列に `{ id, name, field, grade, gen }` の形で登録します。
`gen` は `{ lead, fig, ansFig?, extra?, qs: [{ q, a, ex }] }` を返します（`fig` / `ansFig` はSVG文字列）。
`field` は `num`（数と式）・`func`（関数）・`geo`（図形）・`data`（データの活用）のどれかです。
