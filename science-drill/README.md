# 中学理科 図解ドリル

中学校理科の演習問題を、図（回路図・グラフ・実験装置など）つきで自動生成する1ファイルのWebアプリです。
`index.html` をブラウザで開くだけで動きます（ビルド不要）。

## 収録単元（18）

| 分野 | 単元 |
| --- | --- |
| 物理 | 凸レンズの像（中1）・ばねののび（中1）・圧力（中1）・直列回路とオームの法則（中2）・並列回路（中2）・電力と発熱量（中2）・記録タイマーと速さ（中3）・水圧と浮力（中3） |
| 化学 | 密度（中1）・質量パーセント濃度（中1）・溶解度と再結晶（中1）・金属の酸化と質量（中2） |
| 生物 | 顕微鏡の使い方（中1）・蒸散の実験（中1）・遺伝の規則性（中3） |
| 地学 | 地震の伝わり方（中1）・湿度と露点（中2）・星の日周運動・年周運動（中3） |

## 使い方

- 単元を選び（学年ボタンで一括選択可）、問題数を決めて「新しいプリントを作る」。
- 各問題の「数値を変える」で、その問題だけ別の数値に作り直せます。
- 「解答・解説」を開くと、答えと解き方が表示されます（凸レンズ・遺伝は作図つき解答）。
- シード番号を入力して「再現」すると、同じプリントをもう一度作れます。
- 「印刷する」で名前欄つきのプリントとして印刷できます。解答をすべて開いた状態で印刷すると解答つきになります。

## 単元を追加するには

`genXxx()` 関数を書いて `UNITS` 配列に登録します。関数は
`{ lead, fig, ansFig?, extra?, qs: [{ q, a, ex }] }` を返します（`fig` はSVG文字列）。
